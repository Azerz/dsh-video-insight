# dsh-video-insight · UI/UX 优化方案

> 版本：v1（2026-11-18）｜范围：面板首页、详情页、任务队列、历史/设置 等全部界面
> 前提：功能已冻结，本方案只做「更少步骤、更清晰、更顺手」的设计改造
> 配套：`docs/optimization-proposal.md`（功能路线）· 本文聚焦界面与交互体验

---

## 0. 一句话结论

现在的能力已经超过大多数同类产品（本地转写、画面理解、后台队列、导图/分镜/时间轴联动），**瓶颈不在功能，而在"第一次打开的人不知道能干什么"和"用起来要来回切"**。优化重点三件事：

1. **把「时间轴」变成贯穿全界面的主线索**（播放器、原文、章节、导图、分镜共用同一个"当前秒数"，并且永远可见）；
2. **把「后台任务」从历史行里的一根进度条，升级成全局可见的任务状态**（常驻迷你任务条 + 任务中心）；
3. **把结果从"字很多"改成"先扫后读"**（一句话结论卡 → 要点卡 → 原文），并统一导出/分享出口。

## 1. 现状盘点

### 1.1 信息架构（现状）

```
侧边栏入口（order 30）
└─ 面板
   ├─ 首页 HomeHero：大输入框 + 解析按钮 + 最近分析(10) + [全部解析]
   │   └─ 历史抽屉：搜索 / 全部·已收藏 / 星标 / 删除 / 清空
   ├─ 详情页
   │   ├─ 工具栏：← 返回 · 封面 · 标题 · 平台/时长/作者/播放/点赞 · 历史N · 设置
   │   ├─ 双栏（≥980px）
   │   │   ├─ 左：播放器（可折叠）+ 追问常驻对话
   │   │   └─ 右：页签 [总结｜章节｜原文｜分镜｜思维导图] + 内容区
   │   └─ 窄屏：单列堆叠（播放器→页签→追问）
   └─ 设置弹窗：B 站 Cookie / 本地转写 / 画面理解 / 分析缓存
```

### 1.2 好的地方（保留）

- **边看边读**的左右分栏，是这个品类最合理的基本盘；播放器与正文同屏，比 BibiGPT 的"网页里浮一个卡片"更沉浸。
- **时间戳到处可点并 seek**（总结/原文/章节/导图/分镜都支持）已经是差异化能力，只是"看不见"——用户不知道能点。
- **后台队列 + 进度条**比竞品的"排队弹窗"体验好，只是入口藏在历史行里。
- 暗色适配、中文文案、错误可读性都做得比较扎实。

### 1.3 主要问题（按严重度）

| # | 问题 | 证据/表现 | 影响 |
|---|---|---|---|
| U1 | **首页不知道产品能干什么** | 只有输入框 + 历史列表；三句简介在页面上不显眼 | 新用户不知道怎么用、首屏价值密度低 |
| U2 | **时间戳可点不可感知** | 时间戳样式与普通文字相近，没有 hover 提示的视觉线索（只有 title） | 差异化能力被浪费，用户仍手动拖进度条 |
| U3 | **页面级时间轴缺失** | 只有原文/章节各自高亮；分镜、导图、总结之间没有统一的"当前播放位置"反馈 | 边看边读时"我在哪"不清晰 |
| U4 | **后台任务的可见性不足** | 进度条只在历史行；详情页只有一个小 chip；任务中心不存在 | 用户不知道排了几个、还剩几个，回首页才看见 |
| U5 | **结果呈现以长文为主** | 总结是六段文字（正确），但首屏没有"扫一眼"的层次；章节是列表，没有时间轴可视化 | 长视频"先扫后读"的效率低 |
| U6 | **工具栏信息过载** | 封面+标题+平台+时长+作者+播放+点赞+评论+历史+设置，窄屏会换行 | 视觉噪声大，主操作（重新生成/导出）反而不突出 |
| U7 | **设置弹窗偏工程化** | 模型路径、帧数、阈值等直接暴露 | 普通用户不敢动，高级用户找不到想要的 |
| U8 | **空/错/加载态不统一** | 各页签空态文案、loading 样式不一致；错误有中文但缺少"下一步" | 用户遇到问题不知道怎么办 |
| U9 | **导出/分享入口分散** | 总结有「复制/下载 .md」，原文有「复制全文」，别的页签没有 | 用户想把结果带走时要找 |
| U10 | **窄屏体验** | 单列堆叠后，播放器与页签切换成本高（滚上滚下） | 小窗口/分屏场景可用性下降 |

## 2. 用户与场景

| 角色 | 场景 | 关键诉求 | 当前阻力 |
|---|---|---|---|
| **快速判断者**（多数） | 收到一条视频链接，想知道"值不值得看" | 30 秒内拿到结论 + 章节目录 | 六段总结要读；章节没有概览 |
| **边看边读者** | 一边播放一边看原文/截图，对照精读 | 当前段自动跟随、随时跳转、记笔记 | 跟随只在原文页签；记笔记/收藏入口弱 |
| **批量整理者** | 一次丢 5–10 条链接，晚上统一看 | 队列进度、失败可见、结果统一入口 | 任务中心不存在；结果散在历史里 |
| **内容创作者** | 把视频变成笔记/文章发出去 | 一键导出 Markdown/图片、带时间戳引用 | 只有总结能导出；分镜/导图不能导出 |
| **开发者/重度用户** | 想接自己的模型/改配置 | 设置可读、可验证、可恢复默认 | 设置项工程化，没有"检测"和"重置" |

**两条主流程（理想）**

1. 粘贴链接 → 22 秒内看到"一句话结论 + 章节骨架"（后台继续跑导图/分镜）→ 点章节跳播 → 追问 → 导出笔记。
2. 连贴 8 条 → 顶部出现「解析队列 3/8」→ 期间去干别的 → 完成后 toast + 队列抽屉逐条查看。

## 3. 竞品与前沿参考

| 产品 | 值得抄的点 | 不抄的点 |
|---|---|---|
| **BibiGPT** | 结果卡片分层（一句话→要点→字幕），一键导出 Notion/Obsidian；首页直接给"试用示例" | 功能塞得太满（闪卡/播客/合集），首屏拥挤 |
| **NoteGPT** | 摘要/导图/时间戳三栏并列，导图可导出 PNG | 广告/升级引导打断阅读 |
| **通义听悟** | 时间轴 + 说话人分离的可视化；"章节速览"横向卡片；导出格式全 | 企业级信息密度对个人偏重 |
| **Glarity / Eightify** | 页面内原位标注，点时间戳原位跳转，不打断 | 依赖在原网页上，能力受限 |
| **Linear / Vercel Dashboard** | 空态与骨架屏的克制；命令面板（⌘K）；任务/部署状态常驻顶栏 | 面向工程的术语 |
| **Raycast** | 键盘优先：列表 + 快捷键提示（底部 hint bar） | — |
| **YouTube Studio 分析页** | 指标卡 + 趋势可视化，从数据到洞察的路径 | 过于数据密集 |
| **Readwise Reader** | 阅读进度、标注、导出闭环 | — |

**趋势判断**：2025–2026 的 AI 工具界面共识是——① 首屏即结果（不要营销页）；② 流式与后台任务要"可停、可看、可续"；③ 结果卡片化 + 可导出；④ 时间轴/引用是可信度的载体；⑤ 深浅色、密度、快捷键是被期待的"专业感"。

## 4. 设计原则

1. **先结果，后过程**：能先给结论就不先给加载动画；后台任务用"占位 + 进度"表达。
2. **时间轴贯穿**：任何一处时间都指向同一个播放器位置，任何一处"当前秒数"都能反查所有视图。
3. **就地操作**：在结果旁边给操作（复制/导出/重生成/追问），不要求用户跳页。
4. **渐进披露**：普通人看到 3 个开关，高级用户展开"更多"；设置项按"常用/高级"分区。
5. **状态永远明确**：排队/运行/完成/失败/取消 五态用同一套视觉语言；失败给下一步。
6. **能扫能读**：每屏有一个"3 秒可读"的层（标题、一句话、状态），细节靠展开。
7. **不打断**：抽屉、浮层、命令面板优先于整页跳转；返回不丢进度。
8. **克制的动效**：120–200ms ease-out，只用于状态变化与空间关系，尊重 `prefers-reduced-motion`。

## 5. 信息架构改造

### 5.1 新增两个常驻元素

**A. 全局任务条（Global Job Bar）**——详情页与首页共用

- 位置：面板顶部（工具栏下方或首页输入框上方），高度 40px，可折叠成一个小徽标。
- 内容：`解析队列 3/8 · 当前：正在写总结（42%）` + 「展开」。「展开」打开右侧任务抽屉。
- 无任务时完全隐藏（不占位）。
- 队列 >0 时，即使滚动/切页签/切视频也常驻。

**B. 时间轴胶囊（Timeline Pill）**——详情页

- 位置：右栏页签栏右侧（或工具栏右侧），显示 `00:42 / 20:03` + 小进度条。
- 点击：把播放器滚到可见位置（折叠时展开）。
- 播放时每 250ms 更新（已有 `postMessage` 时间回传，直接复用）。
- 作用：让"当前播放位置"成为全局状态，而不是只在原文页签里。

### 5.2 导航结构调整

```
详情页
├─ 工具栏（两层）
│  ├─ 第一层：← 返回 · 标题（两行截断，hover 显示全集）· 平台徽标 · 后备操作：重新生成 · 导出 · 设置
│  └─ 第二层（可折叠，默认收起）：封面小图 · 作者 · 时长 · 播放/点赞 · 发布日期
├─ 左栏：播放器（sticky）+ 追问（可折叠为底部输入条）
└─ 右栏：时间轴胶囊 + 页签 [总结｜章节｜原文｜分镜｜导图] + 内容区
```

- 页签顺序调整为 **总结 → 章节 → 原文 → 分镜 → 导图**（保持），但每个页签标题右侧加"进度状态点"（已缓存=实心、生成中=跳动、未生成=空心），让用户不用点进去就知道哪些已经好了。
- 追问从"左栏常驻大块"改为 **两段式**：默认底部一行输入（占 56px），展开后变成左栏对话列表。把左栏空间还给"播放器 + 当前小节"。

### 5.3 首页

```
┌───────────────────────────────────────────┐
│           视频解析                        │
│   粘贴链接，30 秒拿结论                    │
│   [ https://...                    ][解析] │
│   支持 YouTube / 哔哩哔哩 · 试一个示例 ▾    │
├───────────────────────────────────────────┤
│ 最近分析            [全部解析] [任务 3]     │
│ ▤ 视频卡片（封面+时长+状态+一句话/进度条）   │
└───────────────────────────────────────────┘
```

改造点：

1. 首屏加 **3 个示例链接**（一个 TED 24 分钟、一个 B 站科普、一个无字幕音乐视频）——用真实样本让用户 10 秒理解"无字幕也能分析"。
2. 最近分析从"行列表"改为 **卡片流**（2 列，窄屏 1 列）：封面 16:9、时长角标、平台角标、标题两行、**一句话总结**（有缓存时显示）、状态徽标（总结/导图/分镜/进度条）。
3. 每张卡片右侧 `⋯` 菜单：重新解析 / 复制链接 / 收藏 / 删除。
4. 「全部解析」按钮改为主次两个：`全部解析`（主）+ `任务队列 N`（次）。

## 6. 关键流程重设计

### 6.1 首次解析（TTFV 目标 ≤ 25s）

现状：提交后等元信息 → 详情页空着等总结流式输出（20–40s），这段时间用户只能看转圈。

目标流程：

1. 提交 → 详情页 **骨架屏**（工具栏、播放器占位、总结占位）立即出现（不白屏，不转圈）。
2. 2s 内：播放器可播、标题/封面到位。
3. 后台任务条出现：`正在读取字幕 → 正在写总结`。
4. **总结流式到达时按小节渲染**：每完成一个 `##` 就出现一张卡（一句话总结先出），而不是等全文。
5. 导图/分镜延迟生成，页签上显示"生成中"小点；完成后 toast「分镜已就绪 · 查看」。

### 6.2 边看边读

- 播放器 sticky；右栏内容随播放自动滚动（原文页签"跟随"默认开，其他页签只在用户点击"跟随"时开）。
- 当前小节（章节/导图分支/分镜格）在各自视图中高亮，且点击"当前"徽标可以"回到当前"。
- 键盘：`空格` 播放/暂停、`←/→` ±5s、`J/K` 上一/下一段、`[`/`]` 上一/下一章节、`/` 聚焦搜索、`Esc` 关闭浮层。
- 选中原文段落 → 浮出操作条：`追问这段` / `复制` / `收藏片段`（需要恢复 host 片段收藏或前端本地收藏）。

### 6.3 批量整理

- 连贴多条：输入框支持"一次粘贴多行链接"，解析按钮变成"解析 N 条"，全部入队。
- 全局任务条实时更新；展开是任务抽屉：运行中（带进度/取消）、排队中（可拖动排序 P2）、已完成（可跳转）、失败（原因 + 重试）。
- 任务全部完成时 toast 汇总：「8 条解析完成，2 条失败 · 重试」。

### 6.4 异常

| 状态 | 用户看到 | 可做的动作 |
|---|---|---|
| 解析失败（网络/平台） | 「这条视频没取到信息」+ 原因一行 | 重试 / 复制链接 / 删除 |
| 无字幕且转写不可用 | 「这个视频没有字幕，可以在设置里开启本地转写」 | 去设置 / 只基于标题分析 |
| 模型不可用 | 「当前模型没响应」+ 建议 | 重试 / 切换模型（跳设置） |
| 长时间无进度 | 「超过 2 分钟没有进展」 | 取消 / 查看日志（折叠） |

## 7. 逐屏方案

### 7.1 工具栏

- 两层结构（见 5.2），默认只显示第一层。
- 主操作固定右侧：`重新生成`（下拉：总结/导图/分镜/全部）、`导出`（下拉：Markdown/复制全文/分镜图/导图 PNG）、`设置`。
- 标题过长时 hover 显示完整标题 + 一键复制标题。
- 封面小图 56×32 圆角 6，点击跳原站。

### 7.2 播放器

- 默认展开，16:9；**高度上限从 42vh 降到 36vh**，把空间还给右栏。
- 折叠状态：变成一条 56px 的"迷你播放条"（封面 + 标题 + 播放/暂停 + 进度条 + 展开），而不是直接消失。
- 播放器下方加一条 **章节刻度条**：按章节比例分段，播放位置小圆点；hover 显示章节名，点击跳章。这条刻度条就是"时间轴可视化的核心载体"。
- 右下角浮层控制：`在平台打开`（外链）、`画中画`（P2，用 Picture-in-Picture API）。

### 7.3 总结

- **首屏卡片化**：
  - 大卡：一句话总结（20–32px 粗体，3 行内）。
  - 三张并排小卡：核心观点（3–5 条）、适合谁看、值得记住的说法（金句）。
  - 「内容脉络」以下用折叠区（默认展开前两个）。
- 每条要点前加"序号胶囊"，hover 显示引用时间点；点击时间跳播。
- 顶部工具条：`复制 Markdown`、`下载 .md`、`重新生成`、`阅读模式`（去掉时间戳，适合导出发公众号）。
- 流式时：小标题出现即渲染骨架边框，正文逐字进入；结束时有轻微 fade。

### 7.4 章节

- 列表 + 时间轴两种视图已具备，默认 **时间轴视图**：横向 100% 刻度条（按章长比例分块），下方是章节卡列表。
- 章节卡：缩略图（左边 96×54）+ 标题 + 一句话摘要（来自大纲 detail）+ 时间徽标。当前章高亮左边框和背景。
- 顶部：「生成画面描述」按钮 + 来源徽标（思维导图 / AI 章节 / 平台章节 / 均分）。
- 「均分」兜底时，提示条 + 一键生成标题（已有）。

### 7.5 原文

- 三栏对齐仍是核心：`时间 · 原文 · 译文`（双语时）。
- 当前段：左侧 2px 高亮条 + 背景色 + 自动滚动（跟随开）。
- 搜索：结果高亮 + 上下跳（`Enter` / `Shift+Enter`）。
- 段级操作 hover 浮出：复制、追问、收藏、时间戳。
- 长文本虚拟滚动（>500 段时）保性能。

### 7.6 导图

- 默认 **fit-to-width**（首次渲染后按容器缩放），工具条：适应宽度 / 100% / 展开全部 / 收起全部 / 导出 PNG / 重新生成。
- 节点 hover：浮出"跳到 0:33"按钮与"以此节点提问"。
- 导图也可以切片：点击分支高亮该分支在原文中的段落（P2）。

### 7.7 分镜

- 每张拼图上方加"第 1/2 张 · 3×8 格"的小标签（已有），下方加**总时间轴刻度**（每格一个刻度点）。
- 点击格子：高亮并 seek；双击：打开大图 lightbox（键盘 ←/→ 翻页）。
- 工具条：附画面描述 / 重新生成 / 导出全部图片（zip）/ 打开大图。
- lightbox 内显示该格时间戳与描述，可"复制时间点"。

### 7.8 追问

- 默认收起为输入条；展开为对话列表（占左栏）。
- 消息气泡：用户右对齐、助手左对齐；回答里的 `[mm:ss]` 保留为可点 chip。
- 回答底部固定一排：`复制` `依据`（展开召回段）`追问这段`。
- 空态：3 个建议 chip（已有）+「可以从原文里选中一段直接追问」。

### 7.9 历史抽屉

- 顶部搜索 + 筛选（全部/已收藏/失败）+ 排序（最近/最久/时长）。
- 每行：封面、标题、平台、状态、星标、删除。
- 支持多选批量（P2）：批量删除/批量重新解析。
- 空态：「还没有记录，粘贴链接开始」+ 示例链接。

### 7.10 设置

- 分区与顺序：`账号`（B 站 Cookie + 状态）→ `转写与画面`（引擎自动/Whisper/SenseVoice + 阈值开关 + 高级折叠）→ `模型`（默认跟随 profile，可覆盖）+ `任务`（并发数）→ `存储`（缓存用量、清理）。
- 每项带"当前值 + 一句人话解释"，高级项收在「高级」折叠里。
- 底部：`恢复默认` `检测环境`（一键检查 ffmpeg/yt-dlp/whisper/模型/网络，输出通过/失败清单）。

### 7.11 空/加载/错误

- 统一三件套：
  - 空态：图标（line 风格）+ 一句主文案 + 一句副文案 + 主按钮。
  - 加载：骨架屏（形状对应当前内容），超过 3 秒出现进度文案。
  - 错误：图标 + 原因 + 下一步按钮（重试/去设置/复制错误）。
- 所有图标用统一 1.5px 线宽、16/20px 两种尺寸。

### 7.12 窄屏（<980px）

- 播放器 sticky 顶部（可折叠成迷你播放条）。
- 页签变为顶部横向滚动 chips。
- 追问变为底部悬浮按钮 → 全屏抽屉。
- 工具栏合并为一层（返回/标题/⋯ 菜单）。

## 8. 视觉规范

### 8.1 设计 token（全部用 DSH 已有的 `--dsw-alias-*`）

| 用途 | token | 说明 |
|---|---|---|
| 页面底 | `--dsw-alias-bg-base` | |
| 卡片/浮层 | `--dsw-alias-bg-layer-1` / `-layer-2` | layer-2 用于 hover/选中 |
| 文字 | `label-primary` / `label-secondary` / `label-tertiary` | 次要信息用 secondary，禁用 tertiary 做正文 |
| 边框 | `border-l1` / `border-l2` | 卡片用 l1，分隔线 l2 |
| 强调/主按钮 | `brand-primary` 作文字色；填充按钮文字用 `bg-base` | 暗色下不会白底白字 |
| 状态 | `state-success/warn/error-primary` | 只用 `-primary` 后缀 |
| 星标/收藏 | `state-warn-primary` | |

### 8.2 排版

- 字号阶梯：12（辅助）/ 13（正文次要）/ 14（正文）/ 16（小标题）/ 20（卡标题）/ 28（一句话结论）。
- 行高：正文 1.65，标题 1.3；中文段落 `letter-spacing: 0.01em`。
- 标题最多 2 行截断 + tooltip；正文段落最大宽度 72ch（避免超长行）。

### 8.3 空间与形状

- 4px 栅格；卡片内边距 12/16；卡片间距 12。
- 圆角：小 6 / 中 10 / 大 14 / 胶囊 999。
- 阴影：只用 1 档（抽屉/弹层）：`0 8px 32px rgba(0,0,0,.12)`；其余靠边框与层级色区分。
- 图标：1.5px 线宽，16/20；播放控件用面性图标。

### 8.4 动效

- 状态变化：120–160ms `ease-out`；弹层进入 180ms `cubic-bezier(.2,.8,.2,1)`；退出 120ms。
- 进度条宽度变化 250ms 线性；骨架屏 shimmer 1.4s。
- `prefers-reduced-motion: reduce` 时全部退化为无动画。

### 8.5 暗色细节

- 半透明遮罩/浮层用 `color-mix(in srgb, var(--dsw-alias-bg-base) 72%, transparent)`，避免纯黑。
- 图片/Video 黑边保留 letterbox；
- 分隔线暗色用 `border-l1` 而不是 `#fff1`。

## 9. 交互与可达性

- 所有可点击区域 ≥32×32；图标按钮必须有 `aria-label` 与 `title`。
- 焦点环：`outline: 2px solid var(--dsw-alias-brand-primary); outline-offset: 2px`，不依赖颜色深浅。
- 颜色对比：正文 ≥4.5:1，大字 ≥3:1；暗色模式单独校验。
- 键盘全可达：Tab 顺序 = 返回 → 工具栏 → 播放器 → 页签 → 内容 → 追问；弹层打开时焦点锁定，Esc 关闭。
- 屏幕阅读器：时间戳按钮文本带"跳转到 0:33 播放"；进度条 `role="progressbar"` + `aria-valuenow`。
- 快捷键注册在面板根节点（不抢全局），Esc 优先关闭最上层浮层。

## 11. 路线图

### P0 · 体感与首屏（约 3–4 人日，可一个版本发）

1. 首页：副标题主张 + 示例链接 + 最近分析卡片流。
2. 全局任务条 + 任务抽屉（复用现有 `/jobs` 轮询）。
3. 工具栏两层化 + 页签状态小点。
4. 统一骨架屏/空态/错误组件（至少覆盖总结、原文、分镜、导图 4 处）。
5. 总结卡片化（一句话大卡 + 三张小卡）。

**验收**：新用户首屏 10 秒内能说出"能干什么"；粘贴后 25 秒内看到一句话结论；回首页能看到所有在跑任务。

### P1 · 时间轴与边看边读（约 5–6 人日）

1. 播放器迷你播放条 + 章节刻度条。
2. 全局当前秒数（时间轴胶囊 + 各视图 `data-current` 统一高亮）。
3. 章节时间轴视图；原文当前段吸附与搜索跳转。
4. 导图 fit-to-width + 导出 PNG。
5. 追问收起式 + 选中文本追问。
6. 设置分区 + 环境检测。

**验收**：播放中切换任意页签都能定位到"当前这一段"；5 个视图的当前项高亮一致。

### P2 · 批量与导出（约 6–8 人日）

1. 多链接一次粘贴/一次入队、任务队列排序与批量重试。
2. 分镜 lightbox + 导出 zip；导出中心（Markdown/PNG/剪贴板）。
3. 历史多选批量操作。
4. 快捷键面板（`?` 唤起）。
5. 窄屏专项（sticky 播放器、悬浮追问）。

**验收**：10 条链接一次入队，全程不需要离开面板；任意结果都能一键导出。

## 12. 度量

**北极星指标**：`每次解析产出的"被使用的结果"数`（点击时间戳 + 追问次数 + 导出次数）/ 解析次数。

| 指标 | 目标 |
|---|---|
| TTFV（提交 → 一句话结论可见） | p50 ≤ 25s，p90 ≤ 45s |
| 首屏「示例链接」点击率 | ≥ 8% |
| 时间戳点击率（有总结的视频） | ≥ 25% |
| 追问会话率 | ≥ 30% |
| 导出率 | ≥ 10% |
| 任务失败率（含重试后成功） | ≤ 5% |

**建议埋点**（前端 `report` 头 + host `/metrics` 增量）：parse_submit、job_start、job_fail、tab_switch、timestamp_click、ask_send、export_click、settings_open、example_click。

## 13. 取舍与风险

- **页签是否合并**：不合并。总结/章节/原文/分镜/导图 是五种不同"阅读姿势"，合并只会让信息更挤；用状态小点和时间轴联动解决"来回切"的痛点。
- **追问放哪**：从常驻左栏改为可收起，牺牲一点"随时问"的顺手，换回播放器与阅读空间；展开态仍占左栏。
- **卡片流 vs 列表**：最近分析改卡片流会增加高度，但首屏价值密度显著提升；超过 10 条时改为"两列卡片 + 查看全部"。
- **P0 不动数据层**：所有改造都能基于现有 API（`/jobs`、`/analysis`、`/outline`、`/storyboard`、`/thumb`），不需要新后端接口（示例链接与埋点除外）。
- **风险**：卡片流会让历史"扫一眼"效率下降 → 用密度切换（紧凑/舒适）在 P2 兜底；时间轴胶囊需要播放器时间回传，B 站无回传 → B 站显示"未知位置"，不做假同步。
